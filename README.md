# Les Saveurs de Pantin

Site de la kermesse du Centre Culturel et Éducatif de Pantin — spécialités turques & street food, les 9, 10 et 11 octobre 2026, 221 avenue Jean Lolive, Pantin. Entrée gratuite.

Une seule page (`index.html`), sans étape de build : three.js et les polices sont chargés depuis des CDN, les photos sont intégrées dans le fichier. Pour la publier, activez GitHub Pages sur la branche `main` (dossier racine).
